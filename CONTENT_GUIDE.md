# Як додавати вміст

Сайт збирає сторінки з Markdown-файлів у `src/content/`:

- `posts/` — дописи для розділу «Нотатки»;
- `projects/` — картки для розділу «Розробки».

Зразок оформлення — `src/content/posts/shablon-dopysu.md`. Він має `draft: true`, тому на сайті його не видно. Щоб подивитися, як виглядають заголовки, код, таблиці й цитати, тимчасово поставте `draft: false` і запустіть `npm run dev`.

## Новий допис

```bash
npm run content:new -- post "Назва допису"
```

Команда створить чернетку в `src/content/posts/`. Напишіть текст у Markdown і змініть `draft: true` на `draft: false`. Після `git push` допис з’явиться в розділі «Нотатки», у RSS і в мапі сайту.

## Нова розробка

```bash
npm run content:new -- development "Назва розробки"
```

Картка буде створена в `src/content/projects/`. Заповніть опис, роль і посилання, а перед публікацією змініть `draft` на `false`.

## Зображення й скриншоти

Покладіть файл поряд із `.md` і вкажіть відносний шлях у `cover`:

```yaml
cover: ./ravlyk-editor.png
coverAlt: "Редактор РАВЛИКа з програмою, що малює квадрат"
```

Astro сам стисне його й віддасть у потрібному розмірі. Усередині тексту зображення вставляють так само: `![Підпис](./screenshot.png)`.

## Контакти, соцмережі, аналітика

Усе це живе в одному файлі — `src/site.config.ts`. Змінювати адресу пошти чи посилання на соцмережі треба там, а не в окремих сторінках.

Щоб увімкнути статистику відвідувань, вставте токен із Cloudflare → Web Analytics у `cloudflareBeaconToken`. Поки рядок порожній, жодних зовнішніх скриптів на сайті немає.

## Картинка для соцмереж

Після зміни імені чи підпису перегенеруйте прев’ю:

```bash
node scripts/build-og-image.mjs
```

## Якщо працюєте тільки через GitHub

Відкрийте потрібну папку в `src/content/`, натисніть **Add file → Create new file** та візьміть за зразок найближчий матеріал. Після збереження GitHub Actions сам збере сайт.

Перед публікацією локально запустіть:

```bash
npm run check
npm run build
```
