# Як редагувати сайт

## Найпростіший спосіб — редактор

```bash
npm run edit
```

Відкрийте **http://localhost:4321/keystatic** — це редактор вмісту. Там усі тексти сайту в звичайних полях, без розмітки й без класів:

- **Сторінки** — тексти головної, «Про мене», «Уроків», «Розробок», «Нотаток», «Контактів»;
- **Матеріали** — дописи й картки розробок;
- **Налаштування** — список публікацій на Друкарні.

Натиснули «Save» — зміни одразу записані у файли проєкту. Далі відкрийте GitHub Desktop, закомітьте й запуште. Через хвилину сайт перезбереться сам.

Редактор працює тільки локально й у зібраний сайт не потрапляє.

## Ніколи не редагуйте теку `dist/`

`dist/` — це результат збірки. Вона в `.gitignore`, тому GitHub Desktop її не показує, і будь-яка правка там зникає при наступному `npm run build`. Редагувати треба або через `npm run edit`, або файли в `src/`.

## Де що лежить

| Що | Файл |
|---|---|
| Тексти сторінок | `src/content/pages/*.json` |
| Дописи | `src/content/posts/*.mdx` |
| Розробки | `src/content/projects/*.mdx` |
| Пошта, соцмережі, аналітика | `src/site.config.ts` |

## Посилання всередині текстів

У полях сторінок працює проста розмітка:

```
[напис посилання](https://адреса)
**жирний**
*курсив*
{email}   — підставить вашу пошту з site.config.ts
```

Зовнішні посилання відкриваються в новій вкладці автоматично.

## Новий допис без редактора

```bash
npm run content:new -- post "Назва допису"
```

Команда створить чернетку в `src/content/posts/`. Змініть `draft: true` на `draft: false`, коли текст готовий.

Зразок оформлення — `src/content/posts/shablon-dopysu.mdx`. Він має `draft: true`, тому на сайті його не видно.

## Зображення й скриншоти

У редакторі є поля «Обкладинка» та «Знімок екрана» — просто перетягніть файл. Вручну: покладіть файл поряд із `.mdx` і вкажіть у `cover`:

```yaml
cover: ./ravlyk-editor.png
coverAlt: "Редактор РАВЛИКа з програмою, що малює квадрат"
```

## Аналітика

Токен із Cloudflare → Web Analytics вставте в `cloudflareBeaconToken` у `src/site.config.ts`. Поки рядок порожній, жодних зовнішніх скриптів на сайті немає.

## Картинка для соцмереж

Після зміни імені чи підпису перегенеруйте прев’ю:

```bash
node scripts/build-og-image.mjs
```

## Перед публікацією

```bash
npm run check
npm run build
```
