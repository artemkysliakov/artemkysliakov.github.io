# Як додавати матеріали

Сайт автоматично збирає сторінки з Markdown-файлів у `src/content/`:

- `posts/` — статті й нотатки;
- `projects/` — освітні та 360°-проєкти;
- `resources/` — матеріали для вчителів, учнів і батьків.

## Найпростіший спосіб

```bash
npm run content:new -- post "Назва статті"
npm run content:new -- project "Назва проєкту"
npm run content:new -- resource "Назва матеріалу"
```

Команда створить готову чернетку з потрібними полями. Відкрийте файл, замініть підказки власним текстом і змініть `draft: true` на `draft: false`. Після `git push` GitHub Actions перевірить і опублікує сайт.

## Без локального редактора

У GitHub можна відкрити потрібну папку `src/content/`, натиснути **Add file → Create new file**, вставити структуру найближчого схожого матеріалу та відредагувати текст у браузері. Зображення варто зберігати в `public/images/` або `src/assets/`.

Перед публікацією локально запустіть:

```bash
npm run check
npm run build
```
